# Проектирование фармацевтических сокристаллов

Хакатонный проект по применению **генеративного машинного обучения** и **эволюционной оптимизации** для поиска перспективных коформеров и проектирования фармацевтических сокристаллов.

Проект выполнен в рамках хакатона **ПРОСТО × Сбер × ИТМО** в 2025 году и основан на исследовательском проекте **GEMCODE (NeurIPS 2024)**.

> Репозиторий содержит хакатонные эксперименты и работу с существующим кодом GEMCODE. Исходная реализация GEMCODE не является моей собственной разработкой.

## Что есть в проекте

- генерация молекулярных структур;
- GAN, Transformer VAE и Conditional VAE;
- эксперименты с GPT-2 и Llama 3;
- предсказание свойств молекул;
- работа с SMILES и SELFIES;
- обработка молекул через RDKit;
- эволюционная оптимизация с GOLEM;
- объединение моделей в единый ML-пайплайн.

## Структура

```text
classifier/          — модели предсказания свойств
generative_models/   — генеративные модели
GOLEM/               — эволюционная оптимизация
pipeline/            — основной пайплайн
utils/               — вспомогательный код
```
